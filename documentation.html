Transformer Architecture

This is the brain of the LLM. It defines the mathematical structure where the learned matrices (weights) reside. Using Apple's MLX (mlx.nn), it implements the standard Decoder-Only Transformer architecture.

Query, Key, and Value Projections

What it does: These instantiate linear transformation layers (matrix multiplications). An incoming character's embedding is multiplied by these matrices to produce three different vectors: a Query (what am I looking for?), a Key (what do I contain?), and a Value (what information do I pass on?).

🧠 Relevance to LLM Weights

These matrices are the absolute core of the model's parameters. Initially, they are filled with random noise. During training, backpropagation adjusts these specific weights so the model learns grammatical rules, context, and associations (e.g., that the word "carbon" should strongly attend to the word "steel").

# Scaled dot-product attention

Attention Score Calculation & Causal Masking

What it does: It calculates how much each character should care about every other character by multiplying Queries and Keys (dot product). The result is divided by the square root of the dimension size to stabilize gradients.

The mask addition is crucial: it forces the upper triangle of the matrix to negative infinity. When softmax is applied, future characters get a probability of 0.

🧠 Relevance to LLM Weights

Without the mask, the model would cheat during training by looking at the answer (the next character) before predicting it. If it cheats, the loss drops to zero instantly, but the weights never actually learn the underlying patterns of the text. The causal mask forces the weights to develop true predictive capabilities.

class TransformerLanguageModel(nn.Module):
    def __init__(...):
        self.word_embedding = nn.Embedding(vocab_size, embed_size)
        self.position_embedding = nn.Embedding(max_length, embed_size)
        self.layers = [TransformerBlock(...) for _ in range(num_layers)]
        self.fc_out = nn.Linear(embed_size, vocab_size, bias=False)

    def __call__(self, x):
        # Create causal mask for language modeling
        mask = nn.MultiHeadAttention.create_additive_causal_mask(seq_length)
        out = self.word_embedding(x) + self.position_embedding(positions)
        for layer in self.layers: out = layer(out, mask)
        return self.fc_out(self.norm_out(out))

Embeddings & The Decoder Stack

What it does: This is the top-level container. word_embedding maps integer IDs to dense vectors. position_embedding gives the model a sense of order (since attention is naturally unordered). The input flows through multiple TransformerBlocks and finally through fc_out to predict the next token's probability distribution.

🧠 Relevance to LLM Weights

The word_embedding matrix (shape: [vocab_size, embed_size]) contains weights that eventually cluster characters with similar functions together in vector space. fc_out (shape: [embed_size, vocab_size]) maps the complex internal representations back into our vocabulary. These boundary layers make up a significant portion of the total parameter count in the final model_weights.safetensors.

train.py

Training Pipeline

This module implements the optimization loop. It takes the model, feeds it data, measures how badly it performs, and uses calculus (gradients) to mathematically adjust the model's weights to perform better next time.

def get_batch(data, seq_length, batch_size):
    # Pick random starting points
    ix = mx.random.randint(0, len(data) - seq_length, (batch_size,))
    
    # Create batches of inputs (x) and targets (y)
    # y is x shifted by 1
    x = mx.stack([data[i:i+seq_length] for i in ix.tolist()])
    y = mx.stack([data[i+1:i+seq_length+1] for i in ix.tolist()])
    return x, y

Autoregressive Data Shifting

What it does: It slices the giant 1D tensor of our text corpus into chunks (batch size) of a specific length (256). Crucially, y is identical to x, but shifted exactly one index into the future.

🧠 Relevance to LLM Weights

This explicitly defines the supervised learning task. The weights learn by trying to make the model output y when given x. If the sequence x is "The high-carbon stee", the target y at the last position is "l". The weights are penalized if they predict "q" instead of "l".

def loss_fn(model, x, y):
    logits = model(x)
    logits = logits.reshape(-1, vocab_size)
    y = y.reshape(-1)
    return mx.mean(nn.losses.cross_entropy(logits, y))

# Value and grad function
loss_and_grad_fn = nn.value_and_grad(model, loss_fn)

def step(x, y):
    loss, grads = loss_and_grad_fn(model, x, y)
    optimizer.update(model, grads)
    return loss

Cross Entropy & Automatic Differentiation

What it does: The loss_fn runs the forward pass, compares the output logits to the ground-truth y, and calculates the Cross-Entropy loss (a measure of how "surprised" the model was by the correct answer).

nn.value_and_grad performs magic: it evaluates the loss, but also builds a computational graph to calculate the exact derivative (gradient) of the loss with respect to every single parameter in the model.

🧠 Relevance to LLM Weights

The optimizer.update(model, grads) line is where the learning actually happens. The AdamW optimizer takes the gradients and slightly shifts all ~5 million weights in the opposite direction of the gradient, minimizing the loss for the next iteration. This turns random matrices into an intelligent text-generation engine.

Autoregressive Sampling

What it does: The model looks at the sequence so far (up to its max context window of 256), calculates the logits for what comes next, and isolates the very last prediction.

It divides by temperature, turns it into a probability via softmax, and then samples from it (rather than just picking the absolute highest value).

🧠 Relevance to LLM Weights

The weights dictate the shape of the logits tensor. If the weights learned well during training, the logits will place high values on mathematically logical next characters. The temperature parameter allows us to override the strictness of the weights: a temperature > 1 flattens the distribution, forcing the model to make "creative" (and sometimes grammatically incorrect) choices outside of what its weights prefer.

bpe.py

The Tokenizer

Transformers cannot read english text; they only perform math on matrices of integers. The tokenizer defines exactly how text is mapped to those integers.

class SimpleTokenizer:
    def train(self, text):
        # Find all unique characters
        unique_chars = sorted(list(set(text)))
        self.vocab_size = len(unique_chars)
        
        # Build vocabulary mapping
        self.vocab = {ch: i for i, ch in enumerate(unique_chars)}
        self.inverse_vocab = {i: ch for i, ch in enumerate(unique_chars)}

Character-Level Dictionary

What it does: Iterates over the entire training corpus to find every unique symbol used (letters, numbers, punctuation, spaces). It assigns a unique integer ID to each.

🧠 Relevance to LLM Weights

The vocab_size variable generated here directly dictates the shape of the model's first and last layers: nn.Embedding(vocab_size, embed_size) and nn.Linear(embed_size, vocab_size). If the tokenizer misses a character during training (e.g., an emoji), the model will never create weights to represent it, and thus can never understand or generate it.

scraper.py

Data Engineering

The quality of the final model is entirely dependent on the quality of the data it learns from. This module interfaces with Wikipedia to build a hyper-specific training dataset.

def clean_text(text):
    # Remove extra whitespace and newlines
    text = re.sub(r'\n+', '\n', text)
    text = re.sub(r'\s+', ' ', text)
    
    # Remove section headers like == See also ==
    text = re.sub(r'==.*?==', '', text)
    return text.strip()

Data Sanitization

What it does: Uses regular expressions to strip out Wikipedia-specific markdown headers and collapse redundant whitespace.

🧠 Relevance to LLM Weights

Language models are spectacular sequence memorizers. If we do not clean the text, the model weights will learn to generate `== See also ==` randomly in the middle of text, thinking it is a core grammatical structure of the English language. Clean data ensures the weights only spend their computational power learning actual linguistic and domain-specific patterns.
